# NoGada

업무 기록을 정리해 주간보고를 만드는 Windows 앱의 **실행 파일 배포용** 저장소예요. 소스 코드는 여기 없어요.

## 받기
1. [최신 릴리스](https://github.com/idontnowcode/NoGada-releases/releases/latest)에서 `NoGada-<버전>-portable.exe`를 받아요.
2. 받은 파일을 실행하면 돼요(설치 없음).

## 처음 실행
- 설정 화면에서 보고서 표지 정보와 Gemini API 키를 넣어요.
- 서명하지 않은 exe라 Windows SmartScreen 경고가 뜰 수 있어요. [추가 정보] → [실행]을 눌러요.

## 업데이트
- 새 버전 exe를 받아 실행하면 돼요. 업무·기록·보고서(`문서\Autoreport` 폴더)와 API 키는 그대로 이어져요.
